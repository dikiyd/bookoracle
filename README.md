# Книжный оракул — публичный пилот

Игра: https://dikiyd.github.io/bookoracle/

Отдельный браузерный экспорт существующего Оракула на Godot 4.7.2, без установки.
Файлы `game/` — готовая сборка, `index.html`, `app.js`, `style.css` — вход, справочник и обратная связь.

## Что означает каталог

`catalog.json` содержит 5000 карточек произведений. Первые 1000 сохраняют прежние игровые ID.
Остальные используют стабильные `wd:Q…`. Поле `coverage=metadata_only` означает только библиографические сведения:
оно не подтверждает знание сюжета и не добавляет вымышленные признаки в угадывание.
`game_catalog` означает наличие в игровом наборе, а не гарантированное угадывание.
Текущий набор персонажей — 2051. Полные тексты современных книг не распространяются.

Источник расширения — Wikidata, CC0; ссылка и ревизия сохраняются в карточке, когда доступны.
Отбор по русским названиям и литературным формам, с приоритетом количества языковых ссылок.
Это не рейтинг продаж и не обещание охватить большинство современной литературы.
Период «1990 и позднее» — технический срез по известной дате произведения.

## Результаты тестов

Перед запуском показано, какие данные собираются; отправку можно отключить.
Сохраняются вопросы, ответы, отмены, отвергнутые догадки, правильный ответ и замечания.
Имена и почта не запрашиваются. Отчёты отправляются отдельному приёмнику; GitHub хранит только публичную сборку.
Отчёты не доступны через публичный GET. Ответы посетителей требуют проверки и не изменяют общий игровой набор автоматически.
При сбое отправки отчёт остаётся в текущей вкладке, доступны повтор и скачивание.

## Запуск и публикация

Локально: `python -m http.server 5179`, затем http://localhost:5179/.
Для отправки приёмник допускает Origin `https://dikiyd.github.io`; локальная проверка использует отдельную тестовую конфигурацию/подмену запросов.
На GitHub: Settings → Pages → Source → GitHub Actions. Workflow `Publish Oracle pilot` публикует содержимое репозитория.
Не включайте Git LFS для WASM/PCK: Pages должен отдавать сами файлы.

`version.json` фиксирует SHA-256 игрового набора. `source/` содержит изолированный исходный Godot-проект.
Для повторного экспорта нужны Godot 4.7.2 и его Web export templates:
`godot --headless --path source --editor --import`
`godot --headless --path source --export-release Web ../game/index.html`

CC0 относится к метаданным Wikidata. Остальным материалам проекта эта лицензия автоматически не назначается.
Godot распространяется по MIT: https://godotengine.org/license/.
